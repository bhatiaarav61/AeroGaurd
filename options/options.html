    Help & Troubleshooting

    Common issues and solutions. If you don't find your answer here, check the full help page.

    🔴 Service worker registration failed (Status 15)

    Go to chrome://extensions/ → Details → Inspect views: Service worker → Check Console for errors. Reload the extension after fixing.

    🔴 SyntaxError: Unexpected token ':'

    Usually a JavaScript syntax error in the background script. Open service worker DevTools to see the exact line.

    🔴 Ads still showing

    Update filter lists, check allowlist, enable "Block Annoyances", or use "Block Element" picker.

    🔴 Site broken / login fails

    Disable for this site in popup, or add to Allowlist. Try disabling "Strict Blocking" or "Block Third-Party Frames".
