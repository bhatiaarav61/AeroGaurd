AeroGuard Help

Answers to the most common questions.

An ad still appears — what do I do?

Click the AeroGuard icon and use Block element to pick the ad directly. For video or network ads, use Report an issue in the popup so the filter lists can be fixed upstream.

How do I pause protection for one site?

Open the popup and switch off the per-site toggle. The site moves to your exceptions and all AeroGuard rules stop applying there until you switch it back on.

Which filter lists are enabled?

AeroGuard ships with EasyList, EasyPrivacy, AdGuard Base/Tracking/Annoyances, uBlock lists, Peter Lowe's, NoCoin, OISD and 20+ regional EasyLists so every country is covered. Manage them all in Settings → Filter lists.

Can I add my own filter subscription?

Yes — go to Settings → Filter lists → Add custom list and paste the URL of an AdBlock Plus-compatible list. It is compiled to native rules the same way the built-in lists are.

Why does the badge show a number?

That is the number of requests AeroGuard blocked on the current page: ads, trackers, malware and annoyances combined.

Videos or a site look broken

Pause AeroGuard for that site from the popup. If that fixes it, please report the site so an exception can be added to the filter lists.
